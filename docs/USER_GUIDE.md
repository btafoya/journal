## Getting Started

### Creating Your Account

1. Navigate to the OpenJournal homepage
2. Click "Sign Up" or use OAuth (Google, GitHub, Microsoft)
3. Complete your profile information
4. Verify your email address (if required)

### First Login

After logging in, you'll see your dashboard with:
- Recent entries
- Quick actions
- Search bar
- Navigation menu

## Creating Entries

### Basic Entry Creation

1. Click the "+ New Entry" button
2. Enter a title for your entry
3. Write your content using the rich text editor
4. Click "Save" or "Publish"

### Rich Text Editor Features

The TipTap editor supports:
- **Bold**, *Italic*, ~~Strikethrough~~ text
- Headings (H1-H6)
- Bulleted and numbered lists
- Block quotes
- Code blocks
- Links
- Images
- Tables

### Entry Status

- **Draft**: Work-in-progress entries (private)
- **Published**: Publicly visible entries (within your workspace)

## Managing Entries

### Editing Entries

1. Click on any entry to view it
2. Click the "Edit" button
3. Make your changes
4. Save your updates

### Deleting Entries

1. Open the entry you want to delete
2. Click the "Delete" button
3. Confirm the deletion

**Note**: Deleted entries are permanently removed and cannot be recovered.

### Version History

Track changes to your entries:
1. Open an entry
2. Click "Version History"
3. View all previous versions
4. Restore a previous version if needed

## Using Templates

Templates help you maintain consistency in your entries.

### Available Templates

- **Daily Journal**: Standard daily journaling format
- **Meeting Notes**: Structured meeting documentation
- **Project Update**: Project status reporting
- **Task Log**: Task tracking and completion
- **Custom**: Create your own templates

### Using a Template

1. Click "+ New Entry"
2. Select "Use Template"
3. Choose your template
4. Fill in the template fields
5. Save your entry

### Creating Custom Templates

1. Go to Settings > Templates
2. Click "Create Template"
3. Define your template structure
4. Save and use in future entries

## Search & Organization

### Searching Entries

Use the search bar to find entries:
- **Full-text search**: Search entry titles and content
- **Fuzzy matching**: Finds entries even with typos
- **Suggestions**: Auto-complete as you type

### Tags

Organize entries with tags:
1. Edit an entry
2. Add tags in the "Tags" field
3. Use tags to filter entries in the dashboard

### Filtering

Filter entries by:
- Date range
- Tags
- Author
- Status (Draft/Published)
- Workspace

## Attachments

Upload and attach files to your entries.

### Supported File Types

- **Images**: JPEG, PNG, GIF, WebP, SVG
- **Documents**: PDF, Word, Excel, PowerPoint
- **Audio**: MP3, WAV, OGG, WebM
- **Video**: MP4, WebM, OGG, QuickTime
- **Text**: TXT, CSV

### Adding Attachments

1. Edit or create an entry
2. Click "Add Attachment"
3. Select your file (max 10MB)
4. Upload and attach to entry

### Security

All uploaded files are:
- Encrypted at rest with AES-256-GCM
- Validated for type and size
- Scanned for security issues

## Comments & Collaboration

Collaborate with team members using comments.

### Adding Comments

1. Open an entry
2. Scroll to the comments section
3. Type your comment
4. Click "Post Comment"

### Mentioning Users

Mention users to notify them:
1. Type `@` in a comment
2. Select a user from the list
3. They'll receive a notification

### Comment Notifications

You'll be notified when:
- Someone mentions you in a comment
- Someone replies to your comment
- New comments are added to your entries

## Workspaces

Organize your entries into separate workspaces.

### Creating a Workspace

1. Go to Settings > Workspaces
2. Click "Create Workspace"
3. Name your workspace
4. Set permissions and preferences
5. Invite team members

### Switching Workspaces

Use the workspace selector in the top navigation to switch between workspaces.

### Workspace Permissions

- **Owner**: Full control over workspace
- **Admin**: Manage users and settings
- **Member**: Create and edit entries
- **Viewer**: Read-only access

## Security Features

OpenJournal implements enterprise-grade security.

### Two-Factor Authentication (2FA)

Enable 2FA for enhanced security:

1. Go to Settings > Security
2. Click "Enable 2FA"
3. Scan the QR code with an authenticator app
4. Enter the verification code
5. Save your backup codes

### Backup Codes

- 10 one-time use codes generated
- Use if you lose access to your authenticator
- Store securely (password manager recommended)

### Password Security

Best practices:
- Use a strong, unique password
- Enable 2FA for additional protection
- Never share your password
- Change password if compromised

### Privacy

Your data is protected:
- Files encrypted at rest
- Secure HTTPS connections
- No third-party data sharing
- GDPR-compliant data handling

- `Ctrl/Cmd + B` - Bold
- `Ctrl/Cmd + I` - Italic
- `Ctrl/Cmd + K` - Insert link

## Import & Export

### Importing Entries

Import entries from other platforms:

1. Go to Settings > Import/Export
2. Click "Import"
3. Select your file format
4. Upload your file
5. Map fields as needed
6. Start import

### Exporting Entries

Export your data:

1. Go to Settings > Import/Export
2. Click "Export"
3. Select entries to export
4. Choose format (JSON, Markdown, PDF)
5. Download export file

## Troubleshooting

### Common Issues

**Problem**: Can't log in
- Solution: Check credentials, reset password if needed
- Enable 2FA recovery if locked out

**Problem**: Files won't upload
- Solution: Check file size (max 10MB) and file type
- Ensure stable internet connection

**Problem**: Search not finding entries
- Solution: Check spelling, try different keywords
- Use filters to narrow results

**Problem**: Notifications not working
- Solution: Check notification settings
- Enable browser notifications

## FAQ

**Q: Is my data secure?**
A: Yes. All files are encrypted at rest with AES-256-GCM, connections use HTTPS, and we implement comprehensive security measures (95/100 security score).

**Q: Can I use OpenJournal offline?**
A: OpenJournal requires an internet connection for full functionality. Offline support may be added in future updates.

**Q: How much storage do I get?**
A: Default file upload limit is 10MB per file. Total storage depends on your deployment configuration.

**Q: Can I customize the appearance?**
A: Yes! Install themes from the marketplace or create your own using Tailwind CSS variables.

**Q: Is there a mobile app?**
A: OpenJournal is web-based and mobile-responsive. Native mobile apps may be developed in the future.

**Q: How do I delete my account?**
A: Go to Settings > Account > Delete Account. This action is permanent and cannot be undone.

**Q: Can I export my data?**
A: Yes. Go to Settings > Import/Export to download your entries in various formats.

**Q: Is OpenJournal open source?**
A: Yes. OpenJournal is MIT licensed and available on GitHub.
