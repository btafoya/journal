## Plugin Context

The context object provided to all plugin lifecycle functions and hooks.

```typescript
interface PluginContext {
  plugin: PluginInfo;
  api: PluginAPI;
  storage: PluginStorageAPI;
  events: PluginEventAPI;
  log: PluginLogger;
}
```

### PluginInfo

```typescript
interface PluginInfo {
  id: string;           // Plugin unique identifier
  version: string;      // Plugin version (semver)
  config: Record<string, any>;  // User configuration
}
```

## Entries API

**Requires**: One or more of `READ_ENTRIES`, `WRITE_ENTRIES`, `DELETE_ENTRIES`

### list()

List journal entries with optional filters.

```typescript
list(filters?: EntryFilters): Promise<EntryMetadata[]>
```

**Parameters**:
```typescript
interface EntryFilters {
  limit?: number;       // Max entries to return (default: 50)
  offset?: number;      // Skip N entries (default: 0)
  dateFrom?: string;    // ISO date string (inclusive)
  dateTo?: string;      // ISO date string (inclusive)
  tags?: string[];      // Filter by tags (OR logic)
  search?: string;      // Full-text search
  sortBy?: 'date' | 'title' | 'updated';
  sortOrder?: 'asc' | 'desc';
}
```

**Returns**:
```typescript
interface EntryMetadata {
  id: string;
  title: string;
  createdAt: string;    // ISO date string
  updatedAt: string;
  tags: string[];
  wordCount: number;
}
```

**Example**:
```javascript
const recentEntries = await api.entries.list({
  limit: 10,
  sortBy: 'date',
  sortOrder: 'desc'
});

const workEntries = await api.entries.list({
  tags: ['work'],
  dateFrom: '2024-01-01'
});
```

### get()

Retrieve a single entry with full content.

```typescript
get(id: string): Promise<EntryData | null>
```

**Returns**:
```typescript
interface EntryData {
  id: string;
  title: string;
  content: string;      // Markdown content
  createdAt: string;
  updatedAt: string;
  tags: string[];
  attachments: Attachment[];
  metadata: Record<string, any>;
}
```

**Example**:
```javascript
const entry = await api.entries.get('entry-123');
if (entry) {
  console.log(entry.title, entry.content);
}
```

### create()

Create a new journal entry.

**Requires**: `WRITE_ENTRIES`

```typescript
create(data: CreateEntryData): Promise<EntryData>
```

**Parameters**:
```typescript
interface CreateEntryData {
  title: string;
  content: string;      // Markdown content
  tags?: string[];
  date?: string;        // ISO date (default: now)
  metadata?: Record<string, any>;
}
```

**Example**:
```javascript
const newEntry = await api.entries.create({
  title: 'Generated Entry',
  content: '# Today\n\nGenerated by plugin',
  tags: ['plugin', 'automated']
});
```

### update()

Update an existing entry.

**Requires**: `WRITE_ENTRIES`

```typescript
update(id: string, data: UpdateEntryData): Promise<EntryData>
```

**Parameters**:
```typescript
interface UpdateEntryData {
  title?: string;
  content?: string;
  tags?: string[];
  metadata?: Record<string, any>;
}
```

**Example**:
```javascript
await api.entries.update('entry-123', {
  tags: [...existingTags, 'reviewed']
});
```

### delete()

Delete an entry permanently.

**Requires**: `DELETE_ENTRIES`

```typescript
delete(id: string): Promise<void>
```

**Example**:
```javascript
await api.entries.delete('entry-123');
```

interface UserData {

## UI API

**Requires**: `MODIFY_UI`

### showNotification()

Display a toast notification.

```typescript
showNotification(
  message: string,
  type?: 'info' | 'success' | 'error' | 'warning'
): void
```

**Example**:
```javascript
api.ui.showNotification('Export completed!', 'success');
api.ui.showNotification('Failed to sync', 'error');
```

### showDialog()

Display a modal dialog.

```typescript
showDialog(options: DialogOptions): Promise<DialogResult>
```

**Parameters**:
```typescript
interface DialogOptions {
  title: string;
  message: string;
  buttons: string[];    // Button labels
  defaultButton?: number;
  cancelButton?: number;
}
```

**Returns**:
```typescript
interface DialogResult {
  button: string;       // Label of clicked button
  index: number;        // Index of clicked button
}
```

**Example**:
```javascript
const result = await api.ui.showDialog({
  title: 'Confirm Delete',
  message: 'This will permanently delete the entry. Continue?',
  buttons: ['Cancel', 'Delete'],
  defaultButton: 0,
  cancelButton: 0
});

if (result.button === 'Delete') {
  // Proceed with deletion
}
```

### registerMenuItem()

Add a custom menu item.

```typescript
registerMenuItem(menu: MenuItemConfig): void
```

**Parameters**:
```typescript
interface MenuItemConfig {
  id: string;
  label: string;
  position: 'entry-menu' | 'main-menu' | 'settings-menu';
  icon?: string;
  shortcut?: string;
  onClick: (context: MenuContext) => void | Promise<void>;
  enabled?: (context: MenuContext) => boolean;
}
```

**Example**:
```javascript
api.ui.registerMenuItem({
  id: 'export-pdf',
  label: 'Export to PDF',
  position: 'entry-menu',
  icon: 'download',
  shortcut: 'Cmd+Shift+E',
  onClick: async (ctx) => {
    await exportToPDF(ctx.entry);
  },
  enabled: (ctx) => ctx.entry !== null
});
```

### registerWidget()

Register a UI widget component.

```typescript
registerWidget(widget: WidgetConfig): void
```

**Parameters**:
```typescript
interface WidgetConfig {
  id: string;
  position: 'dashboard-top' | 'dashboard-bottom' | 'sidebar';
  component: string;    // Component name
  props?: Record<string, any>;
  order?: number;       // Display order (lower = first)
}
```

**Example**:
```javascript
api.ui.registerWidget({
  id: 'mood-widget',
  position: 'dashboard-top',
  component: 'MoodTracker',
  props: {
    period: 'week'
  },
  order: 10
});
```

## Network API

**Requires**: `NETWORK_ACCESS`

### fetch()

Make HTTP requests to external services.

```typescript
fetch(url: string, options?: RequestInit): Promise<Response>
```

**Example**:
```javascript
// GET request
const response = await api.network.fetch('https://api.example.com/data');
const data = await response.json();

// POST request
const result = await api.network.fetch('https://api.example.com/submit', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${apiKey}`
  },
  body: JSON.stringify({ data: 'value' })
});
```

## Storage API

Isolated key-value storage for each plugin.

### get()

Retrieve stored data.

```typescript
get(key: string): Promise<any | undefined>
```

**Example**:
```javascript
const config = await storage.get('config');
const cache = await storage.get('cache:entries');
```

### set()

Store data.

```typescript
set(key: string, value: any): Promise<void>
```

**Example**:
```javascript
await storage.set('lastSync', Date.now());
await storage.set('userData', { count: 42 });
```

### delete()

Remove stored data.

```typescript
delete(key: string): Promise<void>
```

**Example**:
```javascript
await storage.delete('cache:expired');
```

### clear()

Remove all plugin data.

```typescript
clear(): Promise<void>
```

**Example**:
```javascript
await storage.clear();  // Clear all plugin storage
```

### keys()

List all storage keys.

```typescript
keys(): Promise<string[]>
```

**Example**:
```javascript
const keys = await storage.keys();
console.log('Stored keys:', keys);
```

## Events API

Subscribe to and emit events.

### on()

Listen for events.

```typescript
on(event: string, handler: (data: any) => void | Promise<void>): void
```

**Example**:
```javascript
events.on('entry:created', async (entry) => {
  console.log('New entry:', entry.id);
});
```

### off()

Remove event listener.

```typescript
off(event: string, handler: Function): void
```

**Example**:
```javascript
const handler = (entry) => { /* ... */ };
events.on('entry:created', handler);

// Later...
events.off('entry:created', handler);
```

### emit()

Emit custom events.

```typescript
emit(event: string, data?: any): void
```

**Example**:
```javascript
events.emit('my-plugin:sync-complete', {
  timestamp: Date.now(),
  count: 10
});
```

### System Events

| Event | Data | Description |
|-------|------|-------------|
| `entry:created` | `EntryData` | New entry created |
| `entry:updated` | `EntryData` | Entry modified |
| `entry:deleted` | `string` | Entry deleted (ID) |
| `entry:tagged` | `{ id, tags }` | Tags added |
| `user:settings-changed` | `{ key, value }` | Settings modified |
| `plugin:activated` | `{ pluginId }` | Plugin activated |
| `plugin:deactivated` | `{ pluginId }` | Plugin deactivated |

## Error Handling

All API methods may throw errors. Always handle them appropriately:

```javascript
try {
  const entry = await api.entries.get('entry-123');
  if (!entry) {
    log.warn('Entry not found');
    return;
  }
  // Process entry
} catch (error) {
  log.error('Failed to retrieve entry', error);
  api.ui.showNotification('Failed to load entry', 'error');
}
```

## Best Practices

1. **Check permissions**: Verify API is available before use
2. **Handle errors**: Wrap API calls in try-catch
3. **Validate data**: Don't trust external data
4. **Rate limit**: Don't spam API calls
5. **Clean up**: Remove listeners in deactivate hook
6. **Log appropriately**: Use correct log levels
7. **Provide feedback**: Use notifications for user actions
